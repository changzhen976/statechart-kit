# 0.14.0 — P2 事件与运行时增强

> 状态：已实现（0.14.0）
>
> 范围：external-only 可见性、`<send target="#_internal">`、`trySend`。
>
> 真实浏览器 Playwright 回归仍作为后续 0.14.x 工作项。

## 已实现

### 1. external-only 可见性

- `EventVisibility` 增加 `external`；
- 转移生成 `_event.type === 'external'` 守卫；
- 外部事件可触发，`raise` 被拦截；
- 自动延时仍不生成守卫；
- 导入/导出保留 `data-kit-visibility="external"`；
- 混合可见性 warning 覆盖 internal / external / both。

### 2. `<send target="#_internal">`

- 动作 DSL：`send <event> target #_internal`；
- 解析、序列化、导入往返；
- 动作编辑器提供「内部」开关和「内部发送」快捷项；
- 事件目录将 `#_internal` send 标记为 internal；
- 外部 target 仍按原样 warning 后跳过。

### 3. `trySend`

```ts
const result = runner.trySend('go')
if (!result.ok) {
  // session-not-running | session-done | send-failed
  console.log(result.code, result.params)
}
```

`send()` 继续返回 boolean，行为不变。
